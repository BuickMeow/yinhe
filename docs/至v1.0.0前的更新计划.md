# 至v1.0.0前的更新计划

## 重要且复杂新功能

1. 快捷键设置、设置面板分类
2. 美化UI
3. ✅和弦&调式显示
4. 私有颜色事件
5. 框选之后，会弹出一个快捷功能栏，要多一些常用功能
6. 底部栏的tooltip
7. 这个tooltip还要记载鼠标位置
8. AR的CC显示
9. ⏰右键菜单、顶部菜单后面如果能加入快捷键指示就好了（还有置顶图标）
10. ✅右侧面板可以显示选框编辑信息、变速等
11. ✅选框伸缩
12. 敲击测速
13. MIDI输入

## 简单新功能

1. ✅音符创建、拖动反馈
2. ✅编辑拍号、标签、歌词
3. Tempo向上拉可以增加范围，向下拉可以减少范围
4. 选择工具，双击写音符
5. ✅音频设备，在启动的时候要检查一下是否没有上次选的那一个
6. ✅rar压缩包支持&输入密码
7. 追随播放视角添加更多种类

## 功能更改

1. 批量添加面板也是可以滴
2. ✅表格中BPM上限要设置为6000万
3. ✅表格的点要记载x1 x2 y1 y2
4. ✅表格的确认取消按钮应该在一排
5. PR原点设在C4
