# 至v1.0.0前的更新计划

## 重要且复杂新功能

1. 美化UI
2. 框选之后，会弹出一个快捷功能栏，要多一些常用功能
3. AR的CC显示
4. ⏳右键菜单、顶部菜单后面如果能加入快捷键指示就好了（还有置顶图标）
5. 敲击测速
6. MIDI输入
7. 对Bitwig的继续支持
8. 刷子工具、直线工具、剪刀工具
9. 256k支持
10. 瀑布流支持
11. 无键盘/win平板支持

## 简单新功能

1. 钢琴优化
2. “未选择任何内容”空提示标语
3. 音轨清空为默认颜色
4. 缩小选区（查找Domino有多少种功能）

## 功能更改

1. 批量添加面板也是可以滴
2. 颜色统一+尽量减少颜色。有机会检查一下硬编码颜色
3. 更新cargo依赖
4. 改成洋葱皮
5. 一些更改是弹出侧栏，我觉得还是弹出窗口更好一些
6. 网格颜色区分变成粗细区分，改回统一颜色

## bug

1. automation最大高度时，移动automation分割线会相反
2. 在非聚焦位置时，缩放会跟不上
3. ⏳cyber night的a10不是鼓
4. 空区域选择的垂直选框仍可上下移动
5. 图钉添加按钮，按钮瞬时颜色错误
6. 悬浮框背景颜色错误，需要根据主题适配

## 用户反馈

1. ⏳音色库配置可以放在设置页面
