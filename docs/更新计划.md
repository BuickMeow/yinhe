## 最近完成（2026-11-11）

1. 旋钮重做：刻度环与值弧合并、同半径同线宽、支持居中归零（Pan）
2. MIX 界面：默认高度按 BUS 数自动扩展、推子三角、底部控件 Id 冲突修复
3. 设备链：收起态标题四角圆角、竖排字体居中、电源键对齐
4. 音频：暂停/停止保留 delay/reverb 尾音（输入侧淡出 + 尾音渲染）
5. 音频 M0：fade 统一、4 点插值、AudioClipRenderer 拆分
6. 音频 M1 后端：WarpMap / beat 主时基 / tempo follow / 旧工程迁移
