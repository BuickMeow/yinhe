# 文档库

文档按**最后一次实质修改的月份**归档，目录名格式为 `YYYY-MM`。

```text
docs/
├── 2026-06/
├── 2026-07/
├── 2026-08/
├── 2026-10/
├── 2026-11/
└── README.md
```

## 规则

1. 新文档直接放进当前月份目录，例如 `docs/2026-11/`。
2. 文档大改并跨月时，移动到新月份目录，而不是在旧目录里继续堆。
3. 已经过时的文档不删除，留在原月份目录作为历史记录。
4. 长期未完成的想法、待办、计划，统一放根目录 `TODOS.md`。
5. 具体功能的详细 spec、调查记录、性能报告放对应月份目录。
6. 跨文档引用使用完整路径，例如 `docs/2026-11/spec-yinhe-dsp.md`。
